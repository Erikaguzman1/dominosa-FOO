# Dominosa (C)

Implementación en C del puzle Dominosa, desarrollada como práctica de la asignatura Fundamentos de los Ordenadores en la UPC.

## Qué es Dominosa
Un puzle de lógica: sobre una cuadrícula de números hay que colocar fichas de dominó de modo que cada pareja de números aparezca una sola vez.
